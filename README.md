# Lab SQL QC Analysis

SQL and Python project analyzing laboratory quality control (QC) results using SQLite, Pandas, and Matplotlib.

## Project Overview
This project simulates laboratory QC testing data and analyzes:
- Pass vs Fail rates
- Failure trends over time
- Failure counts by test type
- Instrument performance comparison

## Tools Used
- Python
- SQL
- SQLite
- Pandas
- Matplotlib
- Google Colab
- GitHub

## Key Analyses
- SQL aggregation queries
- QC failure tracking
- Instrument comparison analysis
- Time-series trend visualization
- Data visualization and reporting
